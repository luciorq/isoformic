# Summarize Transcript-Level Matrices to Gene Level

Sums the values of all isoforms of a gene. A `length` assay is combined
as the abundance-weighted mean when an `abundance` assay is supplied in
the same list (the `tximport` convention). This is the function used by
[`gene_assays()`](https://luciorq.github.io/isoformic/reference/IsoformicExperiment-accessors.md)
and can be called directly on matrices.

## Usage

``` r
summarize_to_gene(x, tx_to_gene)
```

## Arguments

- x:

  A numeric matrix (transcripts in rows) or a named list of such
  matrices sharing row names.

- tx_to_gene:

  Data frame with `transcript_id` and `gene_id` columns.

## Value

A matrix, or a named list of matrices, with genes in rows.
